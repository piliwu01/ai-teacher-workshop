# AI 教師工作術

60 分鐘教師 AI 研習的互動式 HTML 簡報，內容包含工具選擇、提示詞、備課、出題、簡報、安全查核與課後行動。

## 線上版本

https://piliwu01.github.io/ai-teacher-workshop/

## 操作方式

- 方向鍵或空白鍵：切換投影片
- 滑鼠滾輪或手機滑動：切換投影片
- `H`：操作說明
- `N`：講師備註
- `F`：全螢幕

## 內容說明

- 全站共 22 張投影片。
- 校園手機管理文章與統計均為研習用模擬情境，不代表任何真實學校或研究結果。
- 工具功能、免費額度及學校帳號權限可能調整，請以官方頁面及校方管理設定為準。
- 網站不收集資料，不需登入，也不儲存使用者輸入。

## 本機使用

直接用瀏覽器開啟 `index.html` 即可。若瀏覽器限制全螢幕或字型載入，可透過任何靜態網站伺服器開啟。
